# 🐍 Python Star Pattern Printing: Loops & Alignment

A modular Python script featuring 5 classic console star (`*`) pattern functions to practice nested loops, reverse iteration, and string spacing logic[cite: 5]. This is the fifth installment in a Python learning repository.

## 📌 Patterns Included

The script (`star stuff.py`) defines five standalone functions, with `pyramid()` active by default and the rest ready to uncomment at the bottom of the file[cite: 5]:

1. **`regular_star()`** – Prints a left-aligned ascending right-angled triangle using nested `for` loops[cite: 5].
2. **`reverse_star()`** – Prints a left-aligned descending inverted triangle using reverse `range()` stepping (`-1`)[cite: 5].
3. **`side_pyramid_star()`** – Combines ascending and descending loops to form a right-pointing sideways pyramid[cite: 5].
4. **`mirror_star()`** – Prints a right-aligned ascending triangle using leading space multiplication (`" " * (a - i)`)[cite: 5].
5. **`pyramid()`** – Prints a centered equilateral pyramid using `(n - i - 1)` spaces and `(2 * i + 1)` stars per row[cite: 5].
